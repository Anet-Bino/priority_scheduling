# Priority Scheduling (Non-Preemptive)

## Description
This project implements Priority CPU Scheduling using C.

## Input
- Process ID
- Arrival Time
- Burst Time
- Priority

## Output
- Waiting Time
- Turnaround Time
- Average Waiting Time
- Average Turnaround Time

## How to Run
gcc priority.c -o priority
./priority
